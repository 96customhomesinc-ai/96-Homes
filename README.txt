96 Homes Website

How to preview locally:
1. Install Node.js
2. Open this folder in VS Code
3. Run:
   npm install
   npm run dev

How to deploy:
1. Upload this folder to Vercel
2. Vercel will detect Vite automatically
3. Deploy
4. Add your custom domain 96homes.ca in Vercel settings

Notes:
- Your logo is already included as public/logo-new.png
- The contact form sends inquiries directly to info@96homes.ca through FormSubmit
- IMPORTANT: After deploying, submit the form once. FormSubmit will email info@96homes.ca an activation link. Open that email and approve it before customer inquiries can be delivered.
- After activation, submit a second test inquiry and confirm it arrives in the info@96homes.ca inbox and that the automatic confirmation email is received by the sender.
