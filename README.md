# 96 Homes Website — Version 2

A mobile-friendly React/Vite website prepared for GitHub and Vercel.

## Preview locally
1. Install Node.js.
2. Open this folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local address shown in the terminal.

## Upload to GitHub
1. Create a repository named `96-homes-website`.
2. Upload every file and folder from this project.
3. Commit the files.

## Deploy with Vercel
1. Sign in to Vercel with GitHub.
2. Choose Add New > Project.
3. Import `96-homes-website`.
4. Framework: Vite.
5. Build command: `npm run build`.
6. Output directory: `dist`.
7. Deploy.

## Connect 96homes.ca
Add `96homes.ca` and `www.96homes.ca` under Vercel Settings > Domains, then follow the DNS instructions. Preserve existing email MX records.

## Contact form
The form sends to `info@96homes.ca` through FormSubmit. After launch, submit once and confirm the activation email.

## Editing

- Design: `src/styles.css`
- Images/logo: `public/images/`
